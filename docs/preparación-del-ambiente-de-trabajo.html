Chapter 10 1. Preparación del ambiente de trabajo

El primer paso consiste en instalar y cargar los paquetes necesarios. En este flujo se combinan paquetes para análisis espacial (terra, sf), descarga de datos (geodata, rgbif), modelación de distribución (maxnet), evaluación (pROC) y visualización (ggplot2).

packages <- c(
  "terra", "sf", "dplyr", "geodata", "rgbif",
  "maxnet", "pROC", "ggplot2", "tibble", "stringr"
)

new_packages <- packages[!(packages %in% installed.packages()[, "Package"])]

if(length(new_packages) > 0) {
  install.packages(new_packages)
}
