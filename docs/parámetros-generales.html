Chapter 11 2. Parámetros generales

En esta sección se definen los parámetros principales del análisis: la especie focal, el país, la carpeta de trabajo y el sistema de coordenadas proyectado. El sistema proyectado se utiliza especialmente para calcular distancias a carreteras en metros.

species_name <- "Panthera onca"
country_code <- "CO"
country_name <- "Colombia"

dir_data <- "C:/Users/oscta/OneDrive/Documents/R/Makurhini_manual/Jaguar/"
dir.create(dir_data, showWarnings = FALSE, recursive = TRUE)

# CRS métrico aproximado para Colombia.
# Se usa para calcular distancia euclidiana a carreteras en metros.
crs_col <- "+proj=aea +lat_1=-4 +lat_2=12 +lat_0=4 +lon_0=-74 +datum=WGS84 +units=m +no_defs"
