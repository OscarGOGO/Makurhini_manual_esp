Chapter 13 4. Descarga y depuración de ocurrencias

Las ocurrencias se descargan desde GBIF usando el nombre científico del jaguar. Después se eliminan registros sin coordenadas, registros en coordenadas cero y registros muy antiguos, si se desea limitar temporalmente el análisis.

En este ejemplo se conservan registros a partir de 1980. Este umbral puede modificarse según el objetivo del estudio, por ejemplo, para usar únicamente registros recientes.

occ_raw <- rgbif::occ_search(
  scientificName = species_name,
  country = country_code,
  hasCoordinate = TRUE,
  hasGeospatialIssue = FALSE,
  limit = 5000,
  fields = c(
    "scientificName", "decimalLongitude", "decimalLatitude",
    "year", "basisOfRecord", "coordinateUncertaintyInMeters"
  )
)$data

occ <- occ_raw %>%
  filter(
    !is.na(decimalLongitude),
    !is.na(decimalLatitude),
    !(decimalLongitude == 0 & decimalLatitude == 0)
  ) %>%
  filter(is.na(year) | year >= 1980)

occ_sf <- st_as_sf(
  occ,
  coords = c("decimalLongitude", "decimalLatitude"),
  crs = 4326,
  remove = FALSE
)

# Mantener solo registros dentro del área de estudio
occ_sf <- st_filter(occ_sf, colombia_sf)

plot(st_geometry(colombia_sf), col = "gray90", main = "Ocurrencias GBIF de jaguar")
plot(st_geometry(occ_sf), add = TRUE, pch = 20, col = "red")

cat("Número de ocurrencias dentro del área de estudio:", nrow(occ_sf), "\n")

#> Número de ocurrencias dentro del área de estudio: 1037
