Chapter 12 3. Área de estudio

El área de estudio corresponde a una porción de Colombia. En este ejemplo, el polígono se carga desde un archivo GeoPackage. Este polígono será usado para recortar las variables ambientales y filtrar las ocurrencias de jaguar.

colombia_sf <- read_sf(paste0(dir_data, "area_estudio.gpkg"))

# Convertir a SpatVector para operaciones con terra
colombia_v <- vect(colombia_sf)

plot(st_geometry(colombia_sf), col = "gray90", main = "Área de estudio")
