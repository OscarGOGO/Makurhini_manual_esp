11 Resistencia

La resistencia en conectividad ecológica se refiere al grado en que las características del paisaje dificultan o facilitan el movimiento de los organismos entre parches de hábitat. A diferencia de una simple medida de distancia geográfica, la resistencia incorpora la calidad y permeabilidad de la matriz, considerando que distintos tipos de cobertura, usos de suelo, carreteras, áreas urbanas, pendientes o niveles de perturbación pueden representar diferentes costos de desplazamiento para una especie. En este sentido, una zona de bosque continuo o de alta idoneidad ambiental puede tener baja resistencia, mientras que una carretera, un cultivo intensivo o un área urbanizada pueden tener alta resistencia. Por ello, las superficies de resistencia son hipótesis espaciales sobre cómo una especie percibe y atraviesa el paisaje, y son fundamentales para modelar corredores, rutas de menor costo, flujo de corriente y conectividad funcional.

Existen grandes aproximaciones para modelar resistencia, entre ellas se destacan: 1) Paisaje o agnóstico y 2) funcional. En el primero se busca mapear la naturalidad y el grado de transformación humana, un ejemplo es la huella espacial humana. Mientras que en el segundo por lo general la resistencia se asocia a la idoneidad de hábitat, donde una mayor idoneidad representa unamenor resistencia al movimiento.

En el siguiente ejemplo modelaremos la resistencia desde una perspectiva funcional, usando un modelo de distribución potencial.

11.1 Ejemplo: Introducción

Este documento presenta un flujo reproducible para construir un modelo de distribución potencial (MDP) del jaguar (Panthera onca) en Colombia y, posteriormente, transformar la idoneidad ambiental estimada por el modelo en una superficie de resistencia. La lógica general es que las áreas con mayor idoneidad ambiental pueden interpretarse como zonas de menor costo para el movimiento, mientras que las áreas con baja idoneidad pueden representar una matriz más resistente o menos permeable.

El flujo se organiza como un pequeño capítulo metodológico: primero se preparan las variables ambientales, después se descargan y depuran las ocurrencias, posteriormente se ajusta un modelo tipo MaxEnt con maxnet, y finalmente se transforma la predicción del MDP en una superficie de resistencia mediante una transformación monomolecular.

11.1.13 Reducción de colinealidad

La colinealidad entre variables puede dificultar la interpretación del modelo. Aquí se usa una regla simple: eliminar variables altamente correlacionadas, usando un umbral de correlación de 0.75. Este paso no reemplaza una selección ecológica de variables, pero ayuda a reducir redundancia.

remove_correlated <- function(df, cutoff = 0.75) {
  
  cormat <- cor(df, use = "pairwise.complete.obs")
  vars <- colnames(cormat)
  
  keep <- rep(TRUE, length(vars))
  names(keep) <- vars
  
  for(i in seq_along(vars)) {
    if(keep[i]) {
      high_cor <- which(abs(cormat[i, ]) > cutoff)
      high_cor <- high_cor[high_cor > i]
      keep[high_cor] <- FALSE
    }
  }
  
  return(names(keep[keep]))
}

env_names <- names(env)

vars_keep <- remove_correlated(
  sdm_df[, env_names],
  cutoff = 0.75
)

cat("Variables retenidas:\n")

11.1.15 Ajuste del modelo con maxnet

maxnet implementa un modelo tipo MaxEnt usando regularización. En este ejemplo se usan clases de features lineales, cuadráticas, producto e hinge (lqph). El resultado es un modelo de presencia-background que estima la idoneidad relativa del paisaje para el jaguar.

mx_formula <- maxnet.formula(
  p = train$pa,
  data = train[, vars_keep],
  classes = "lqph"
)

mod_jaguar_colombia <- maxnet(
  p = train$pa,
  data = train[, vars_keep],
  f = mx_formula
)

print(mod_jaguar_colombia$call)
#> glmnet::glmnet(x = mm, y = as.factor(p), family = "binomial",

11.1.16 Evaluación con AUC

El AUC resume la capacidad del modelo para diferenciar presencias de puntos de fondo. Valores más altos indican mayor discriminación, aunque el AUC debe interpretarse con cuidado en modelos presencia-background, especialmente cuando el background no representa ausencias reales.

test_pred <- predict(
  mod_jaguar_colombia,
  newdata = test[, vars_keep],
  type = "cloglog"
)

auc_value <- pROC::auc(test$pa, test_pred)

cat("AUC del modelo para Colombia:", as.numeric(auc_value), "\n")
#> AUC del modelo para Colombia: 0.8790535

11.1.18 Mapa binario de distribución potencial

Para convertir la predicción continua en un mapa binario, se aplica un umbral. En este ejemplo se usa el percentil 50 de las predicciones en las presencias, una regla común para evitar que unos pocos registros marginales definan todo el rango potencial. Este valor puede modificarse según el objetivo del estudio.

threshold_prob <- 0.5

pres_pred <- terra::extract(
  pred_jaguar_colombia,
  occ_clean_vect,
  ID = FALSE
)[, 1]

threshold_p50 <- quantile(
  pres_pred,
  probs = threshold_prob,
  na.rm = TRUE
)

jaguar_binary_colombia <- pred_jaguar_colombia
jaguar_binary_colombia[pred_jaguar_colombia >= threshold_p50] <- 1
jaguar_binary_colombia[pred_jaguar_colombia < threshold_p50] <- 0

names(jaguar_binary_colombia) <- "jaguar_binary_50_colombia"

plot(

11.1.19 Importancia aproximada de variables

maxnet no genera una tabla de importancia equivalente a la salida clásica de MaxEnt Java. Sin embargo, es posible inspeccionar los coeficientes no nulos del modelo. Como algunas variables pueden aparecer en varias features, se agrega la importancia por variable original sumando los valores absolutos de sus coeficientes asociados.

coef_mod <- mod_jaguar_colombia$betas
coef_mod <- coef_mod[coef_mod != 0]

coef_df <- tibble(
  feature = names(coef_mod),
  coefficient = as.numeric(coef_mod),
  importance = abs(coefficient)
) %>%
  arrange(desc(importance))

get_original_var <- function(feature_name, vars_model) {
  
  matched <- vars_model[str_detect(feature_name, fixed(vars_model))]
  
  if(length(matched) == 0) {
    return(feature_name)
  } else {
    return(matched[which.max(nchar(matched))])
  }
}

coef_df <- coef_df %>%
  mutate(
    variable = sapply(feature, get_original_var, vars_model = vars_keep)
  )

var_importance <- coef_df %>%
  group_by(variable) %>%
  summarise(
    importance = sum(abs(coefficient)),
    n_features = n(),
    .groups = "drop"
  ) %>%
  arrange(desc(importance))

print(var_importance)

11.1.20 Transformación del MDP a resistencia

La conectividad funcional requiere una superficie que represente el costo o dificultad de movimiento. Aquí se transforma la idoneidad del MDP en resistencia. Primero se invierte la idoneidad:

\[ \text{costo base} = 1 - \text{idoneidad} \]

Así, las áreas de alta idoneidad tienen bajo costo base, mientras que las áreas de baja idoneidad tienen alto costo base.

sdm <- pred_jaguar_colombia

# Asegurar que el SDM esté entre 0 y 1
sdm <- terra::clamp(sdm, lower = 0, upper = 1)

plot(sdm, main = "MDP / idoneidad de jaguar")

# Alta idoneidad = bajo costo base
# Baja idoneidad = alto costo base
cost_base <- 1 - sdm
names(cost_base) <- "cost_base_inverse_sdm"

cost_base[cost_base < 0] <- 0
cost_base[cost_base > 1] <- 1

plot(cost_base, main = "Costo base: 1 - SDM")

11.1.21 Transformación monomolecular con ResistanceGA2

La transformación monomolecular permite convertir el costo base en una superficie de resistencia no lineal. El parámetro shape controla la curvatura de la transformación, mientras que max define el valor máximo de resistencia. En este ejemplo se usan valores intermedios (shape = 2, max = 100) como hipótesis de resistencia, no como valores calibrados empíricamente.

# Si no tienes ResistanceGA2 instalado, instálalo antes de correr esta sección.
# La forma de instalación puede depender de tu versión local de R y del repositorio que uses.
# install.packages("remotes")
# remotes::install_github("wpeterman/ResistanceGA2")
library(ResistanceGA2)

shape_value <- 2
max_resistance <- 100

resistance_mono <- Resistance.tran(
  transformation = "Monomolecular",
  shape = shape_value,
  max = max_resistance,
  r = cost_base
)

plot(
  resistance_mono,
  main = paste0(
    "Resistencia monomolecular\nshape = ",
    shape_value,
    ", max = ",
    max_resistance
  )
)
writeRaster(
  resistance_mono,
  filename = file.path(dir_data, "jaguar_resistance_monomolecular_colombia.tif"),
  overwrite = TRUE
)

11.1.22 Curva de transformación

Antes de usar una superficie de resistencia en conectividad, conviene visualizar la forma de la transformación. La curva ayuda a entender si el modelo penaliza suavemente o fuertemente las áreas de baja idoneidad.

plot_trans <- Plot.trans(
  PARM = c(shape_value, max_resistance),
  Resistance = cost_base,
  transformation = "Monomolecular"
)

plot_trans

11.1.23 Del mapa binario a parches de hábitat

El mapa binario puede usarse para identificar parches potenciales de hábitat. Aquí se agrupan celdas contiguas usando conectividad de ocho direcciones. Este paso puede servir como base para análisis posteriores de conectividad estructural o funcional.

parches <- patches(
  jaguar_binary_colombia,
  directions = 8,
  zeroAsNA = TRUE
)

plot(parches, main = "Parches de hábitat potencial")

parches_sf <- as.polygons(parches) %>%
  st_as_sf()

plot(parches_sf, main = "Parches como polígonos")
write_sf(parches_sf, file.path(dir_data, "parches_sf.gpkg"), delete_layer = TRUE)

11.1.24 Interpretación general

El flujo genera tres productos principales. El primero es el MDP continuo, que representa la idoneidad ambiental relativa para el jaguar. El segundo es el mapa binario, que delimita áreas potencialmente adecuadas a partir de un umbral. El tercero es la superficie de resistencia, que traduce la idoneidad del MDP en costos potenciales de movimiento.

La resistencia monomolecular debe entenderse como un escenario de conectividad. En este caso, el supuesto central es que la resistencia aumenta de manera no lineal conforme disminuye la idoneidad del paisaje. Para análisis aplicados, se recomienda comparar varios valores de shape y max, o calibrar la superficie con datos independientes de movimiento, genética o detección.

11.1.25 Recomendaciones metodológicas

Para fortalecer este flujo en un análisis formal, se recomienda:

  1. Usar validación espacial en lugar de una partición aleatoria simple.
  2. Evaluar sesgo de muestreo en las ocurrencias de GBIF.
  3. Comparar distintos conjuntos de variables ambientales.
  4. Probar varios umbrales de binarización.
  5. Realizar análisis de sensibilidad de los parámetros shape y max.
  6. Calibrar o validar la resistencia con datos independientes cuando sea posible.

En términos ecológicos, el MDP responde principalmente a la pregunta: ¿dónde existen condiciones ambientales adecuadas para el jaguar? En cambio, la superficie de resistencia responde a una pregunta diferente: ¿qué tan difícil podría ser para el jaguar moverse a través del paisaje? Aunque ambos mapas están relacionados, no representan exactamente el mismo proceso ecológico.
